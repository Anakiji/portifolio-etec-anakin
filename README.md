🌐 Portfólio Pessoal - Etec AMS

> Projeto de portfólio web desenvolvido para a disciplina de Desenvolvimento de Sistemas na Etec.

📌 Visão Geral do Projeto
Este projeto é um portfólio pessoal e acadêmico desenvolvido para apresentar meus projetos, habilidades técnicas e jornada no curso de Desenvolvimento de Sistemas. A aplicação conta com interface responsiva, navegação intuitiva e integração com o GitHub

 🔗 Link do Projeto no Ar
 
Acesse a aplicação rodando na Vercel:

👉 **[Acessar Portfólio na Vercel](https://portifolio-etec-anakin.vercel.app)**

---

## 🛠️ Tecnologias e Bibliotecas Utilizadas

* **HTML5**: Estruturação semântica de todo o conteúdo.
* **CSS3**: Estilização personalizada, animações e temas visuais.
* **Bootstrap 5**: Framework para responsividade e layout da navbar.
* **Bootstrap Icons**: Biblioteca de ícones para botões e links.
* **Google Fonts**: Tipografia (*Inter* e *Poppins*).
* **Vercel**: Plataforma para hospedagem e *deploy* contínuo.
